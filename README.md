# Secretaria de Missões — IDPB

Site da Secretaria do Ministério de Missões da Igreja de Deus Pentecostal do Brasil: igrejas, regiões, pastores e missionários, graus ministeriais, censo 2026.1 e relatórios.

Esta é a **versão pública**: não contém RG, CPF, data de nascimento, endereço, telefone nem e-mail. Os dados completos e a edição ficam apenas na versão interna da secretaria.

O site é um único arquivo (`index.html`) publicado pelo GitHub Pages.
